# Cleaning Carpet Simulator

Jogo 3D em primeira pessoa de lavar tapetes, feito com HTML, CSS, JavaScript e three.js.

## Como jogar

| Tecla | Ação |
|---|---|
| WASD | andar |
| Shift | correr |
| Mouse | olhar |
| Ctrl ou Command | travar ou soltar o mouse |
| Clique ou Espaço | usar a ferramenta ou sentar no computador |
| F | ver a sujeira em laranja · enrolar o tapete limpo |
| 1 a 6 | bucha, mangueira, rodo, vassoura, polisher, varinha |
| Q e E | girar sem o mouse |

1. Esfregue o tapete com a bucha: saem espuma e bolhas marrons.
2. Molhe as bolhas com a mangueira: elas viram bolhas de desenho.
3. Empurre as bolhas limpas com o rodo até o ralo da parede para ganhar dinheiro.
4. Com o tapete limpo, aperte F perto dele para enrolar e sente no computador para pedir outro e comprar melhorias.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub e envie o `index.html` e este `README.md`.
2. No repositório, vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.
4. Depois de um ou dois minutos o jogo fica no ar em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

O jogo carrega o three.js e as fontes pela internet, então precisa de conexão para abrir. O progresso fica salvo no navegador de cada jogador.
